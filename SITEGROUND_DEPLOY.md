# SiteGround playtest — pfc.cliffslunchclub.com

GitHub source is private: `cliffslunchclub/PokeFC`. SiteGround serves only the `dist/` output generated by `scripts/build-siteground.sh`.

## Public playtest sections

- **Home / Free Builder:** https://pfc.cliffslunchclub.com/
- **Challenges:** https://pfc.cliffslunchclub.com/challenge/
- **Franchise (32 gyms):** https://pfc.cliffslunchclub.com/franchise/

The archived 16-gym Franchise and retired Arcade are preserved in private GitHub but **not published**. The SiteGround deployment sync removed the old public `legacy-v07c/` folder on the three-section migration.

## Automatic deployment

GitHub Actions workflow `.github/workflows/deploy-siteground.yml` builds and tests the site, then uploads changed files over certificate-validated FTPS. Pushes to `main` affecting playable code automatically publish; manual runs are also available in Actions.

The dedicated FTP account has its home set to the `pfc.cliffslunchclub.com` subdomain folder, **one level above** `public_html`. The deployment's destination `./public_html/` is relative to that dedicated FTP home, not the primary website's root.

GitHub repository secrets, **never** committed to source or pasted into chat:

- `SG_FTP_HOST` — the hostname that matches the server's FTPS certificate
- `SG_FTP_USER` — the dedicated subdomain FTP account username
- `SG_FTP_PASSWORD` — that account's password

## Scope and safeguards

- **Published:** homepage, browser Free Builder, Challenge UI and its special item data, 32-gym Franchise UI/scripts, and pinned TacticMesh browser runtime with MIT license and notices.
- **Not published:** old `legacy-v05/` or `legacy-v07c/` interfaces, Python/Node developer tests, calibration reports, GitHub repository internals, development documentation or optimized-engine experiment files.
- **Persistence:** Free Builder, Challenges and Franchise keep separate browser saves in localStorage. Public website users can inspect all browser-delivered JS despite the private GitHub repository.
- **Status:** playable development builds; both match simulation and Challenge Mode gameplay remain in alpha.

## Deploy troubleshooting

1. Visit the GitHub Actions deployment workflow and open its most recent run.
2. Check the test, build validation, and FTPS upload steps.
3. For FTPS certificate errors, use the certified server hostname from SiteGround credentials; **never disable TLS certificate validation**.
4. Verify `pfc.cliffslunchclub.com` points to its own `public_html` folder in SiteGround.
5. For stale pages, use a hard refresh to invalidate local browser caches.
